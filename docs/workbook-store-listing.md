## Main description - customer-facing draft

Already have chess lines you want to use in a lesson? PGN Workbook lets you choose positions from a PGN file and export two separate PDFs: a writing sheet for the student and a key containing the supplied continuations and comments for the coach.

Open the application, load your PGN, select positions, write a common question and export. Each selected position gets its own page. A bundled example lets you try the workflow immediately. Files are processed locally by the application; normal importing and exporting do not upload your PGN or require an account.

### Included in the download

- Windows x64 application folder: extract it and run `TrickfishWorkbook.exe`, keeping `_internal` beside it. No separate Python installation is needed.
- Bundled example with a board preview and position selection.
- Student PDF with a board, question and writing space.
- Separate coach PDF with the selected position's comment and up to eight plies of its supplied first continuation.
- Source-code ZIP, build instructions, GPL terms and third-party notices.

### Please check before buying

This is an unsigned preview build. It has been exercised on the developer's Windows machine and in Windows CI, not certified across all clean Windows systems. If operating-system protections block it, report the message; do not disable those protections. This listing does not offer macOS, Linux or mobile binaries.

The program does not analyze positions with an engine, generate proven tactical solutions or diagnose a player. It formats your supplied material. A legal continuation is not necessarily the best move; review your questions and answers before teaching with them. There is no curriculum or opening course included.

Limits are 5 MB per PGN, 2000 imported positions and up to 50 selected positions per workbook. Each selected position has one page in each PDF. Comments are limited to the selected node; future comments and all alternative answers are not combined into a single key. Long comments may need shortening. Pages are fixed-format with a common prompt; there is no drag-and-drop page editor or per-position question editor in this version.

The student PDF hides source comments and continuations. It does not remove answers you type into the shared title or prompt. Terminal positions use an assessment question when the default prompt is unchanged. Custom prompts are kept as supplied.
