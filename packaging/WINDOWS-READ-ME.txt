TRICKFISH PGN WORKBOOK - INTERNAL WINDOWS PROTOTYPE

Extract the complete ZIP into a writable folder. Double-click
TrickfishWorkbook.exe. Keep the _internal folder beside the executable.
Python does not need to be installed separately.

Click Open example, select positions and export into a NEW output folder.
Open student.pdf and coach.pdf using your usual PDF reader. Keep the coach
file separate from student copies. PGN comments and supplied continuations
are not certified best answers. Review material before teaching with it.
